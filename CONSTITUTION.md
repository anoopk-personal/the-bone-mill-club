# The Bone Mill Club

**An Autonomous Digital Workforce**
**Constitution | Version 1.2**

## Purpose

Build a personal fleet of cloud-based AI agents with distinct roles, identities, and permissions. Agents may operate independently or collaborate, remain securely accessible from anywhere, and run economically under owner control.

## Principles

### 1. Security without compromise

Security is non-negotiable. Every agent and integration requires appropriate isolation, explicit permissions, and least-privilege access. Private information stays private.

### 2. Cost-conscious by design

This is a personal project. Every paid service must justify its cost. Overall and per-agent budgets require owner approval; agents may spend autonomously only within those limits.

### 3. Independent, composable agents

Each agent has its own identity, responsibilities, and capabilities. Agents can work alone or collaborate without inheriting each other's privileges.

### 4. Autonomy with human control

Agents can act within defined, revocable authority. Consequential actions require owner approval. Access, spending, and operations remain under owner control.

### 5. Accessible without waste

Agents must be securely reachable from anywhere with an internet connection. Idle infrastructure should cost as little as practical.

### 6. Pragmatic portability

Core agent logic should not depend unnecessarily on a particular cloud, model, harness, or framework. Provider-specific services are acceptable when the benefits outweigh the lock-in.

### 7. Observable and accountable

Agent activity, health, and cost must be measurable. Logs and metrics should be useful, private, and economical.

### 8. Open source, private operations

Code and non-sensitive engineering work can be public. Credentials, personal data, operational state, and privileged access cannot. Contributions never grant access to private systems.

### 9. Simplicity over ceremony

Build against real needs, test what is shipped, and document significant decisions briefly. Avoid speculative architecture, unnecessary abstractions, and paperwork for its own sake.

## Governance

These principles guide architecture and operational decisions. Changes to this constitution require owner approval. Implementation details belong in code, tests, and short decision records when needed.
